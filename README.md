# 🎓 Географический клуб Оксфорда и Кембриджа · имени Лейлы

Игра-тренажёр по географии, сделанная с любовью для Лейлы — будущей студентки Оксфорда. Современный дизайн с розовыми акцентами, фото Лейлы в меню и настоящая векторная карта в стиле Google Maps (без подписей стран, чтобы не подсказывала). Все названия дублируются по-английски, департаменты Франции — по-французски.

## Как запустить

**На компьютере:** открой `index.html` двойным кликом. Для карты и онлайн-режима нужен интернет (карта подгружается с OpenFreeMap).

**На телефоне (через Wi-Fi с компьютера):**
1. На компьютере: `node "tools/serve.js"`
2. На телефоне открой `http://<IP-компьютера>:8741`

## 🌐 Онлайн-дуэль (с разных устройств)

1. Отправь Лейле папку с игрой (или задеплой на любой статический хостинг — Netlify Drop, GitHub Pages).
2. Оба открывают игру → табличка «Онлайн-дуэль».
3. Один нажимает «Создать комнату» и говорит второй **код из 4 букв**.
4. Вторая вводит код → «Подключиться». Хост выбирает режим и настройки.
5. Играете одновременно: каждый отвечает у себя, после обоих ответов — общее раскрытие с очками. «Дальше» и реванш запускает хост.

Соединение — напрямую между устройствами (WebRTC/PeerJS). Если соединение оборвётся, игра скажет об этом и вернёт в меню.

## Режимы

| Режим | Что делать |
|---|---|
| 🏛️ Столицы мира | Показано название столицы — поставь метку на карте |
| 🗺️ Страны мира | Найди страну на карте |
| 🚩 Флаги | Выбери правильный флаг из трёх (можно выбрать континент) |
| 📍 Флаги: на карте | Показан флаг — найди страну на карте |
| 🥖 Регионы Франции | Найди департамент (96 департаментов) |
| 🤠 Штаты США | Найди штат (все 50) |
| ⛰️ Моря и горы | Области морей и хребтов на рельефной карте (Terrain) — попади в область |
| 🍷 Винные регионы мира | Терруары планеты + карточки сомелье с 5 винами |
| 🍇 Винные регионы Франции | От Шампани до Прованса + карточки сомелье |
| 🏞️ Известные места | Озёра, водопады, острова, пустыни — по фото |
| 🗽 Памятники мира | Знаменитые сооружения — по фото |
| 🎲 Микс | Всё вперемешку |
| 🌐 Онлайн-дуэль | Любой режим — с разных устройств по коду |

## Настройки

- **Вопросов:** 5 / 10 / 20 / 50 / 100 / Все (для Франции «Все» = 96, для штатов = 50, для стран = до 196)
- **Время на ответ:** ∞ / 15 / 30 / 60 сек
- **Сложность:** известные страны / все страны
- **Континент** (для флагов): весь мир / Европа / Азия / Африка / Америка / Океания

## Подсветка и карточки

- Область/страна под кликом подсвечивается синим до подтверждения.
- Правильная область — **зелёная** (остаётся до конца матча), промах — **красным** там, куда попал.
- После каждого ответа — **карточка-справка**: фото и интересные факты об объекте (вкл/выкл в настройках).

## Дуэль

- **На одном устройстве:** по очереди на один и тот же вопрос; ответ первого скрывается («Передай устройство — не подглядывай!»), потом общее раскрытие.
- **Онлайн:** одновременно, у каждого свой таймер.
- 🎯 Попадание — 1000 очков, дальше очки тают с расстоянием. Угаданные регионы Франции/США остаются зелёными до конца матча.
- Общий счёт побед сохраняется — на доске в меню и под кубком 🏆.

## Фото Лейлы

Кликни по кружку с сердечком в меню и выбери фотографию — она сохранится в игре (на этом устройстве). Либо положи файл `assets/leyla.jpg` в папку игры — тогда фото будет везде.

## Карта

- Векторная карта MapLibre + OpenFreeMap в стиле Google Maps без подписей: белая суша, голубая вода, рельеф, зелёная растительность. Плавный быстрый зум колёсиком/пинчем, инерционный скролл, авто-подлёт к ответу.
- Клик по фото в вопросе — увеличить.
